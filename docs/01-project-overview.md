# 📊 项目概述

## 🎯 项目简介

AI股票聊天助手是一个基于人工智能的智能投资分析平台，结合了现代Web技术与量化分析算法，为个人投资者提供专业级的股票投资决策支持。

### 核心价值
- **🤖 AI驱动决策**：将人工智能引入投资决策流程，提供数据驱动的投资建议
- **📊 实时数据分析**：基于最新市场数据的实时分析和决策支持
- **🔄 自动化管理**：减少手动操作，提升投资管理效率
- **💡 智能筛选**：自动发现投资机会，不错过市场热点
- **📈 专业级工具**：为个人投资者提供机构级的分析工具

## 🏗️ 技术架构

### 前端技术栈
- **React 18** - 现代化UI框架
- **TypeScript** - 类型安全的JavaScript
- **Tailwind CSS** - 实用优先的CSS框架
- **Vite** - 快速构建工具
- **WebSocket** - 实时通信

### 后端技术栈
- **FastAPI** - 高性能异步Web框架
- **Python 3.9+** - 主要开发语言
- **SQLite** - 轻量级数据库
- **AkShare** - 股票数据源
- **OpenAI API** - AI模型集成

### 核心特性
- **实时WebSocket通信**：支持实时聊天和数据更新
- **模块化服务架构**：清晰的服务边界和职责分离
- **异步并发处理**：充分利用Python asyncio提升性能
- **类型安全设计**：端到端TypeScript类型检查

## 🚀 创新技术亮点

### 1. MCP协议集成
项目创新性地使用Model Context Protocol连接数据源，实现了：
- 统一的数据接口标准
- 可扩展的数据源管理
- 高效的数据获取机制

### 2. AI策略分析引擎
结合实时数据和AI模型的智能投资策略生成：
- 多维度数据融合分析
- 基于Qwen-Coder-Plus的策略生成
- 量化评分和风险评估体系

### 3. 深度分析算法
专业的股票分析算法系统：
- 波动性分析（权重60%）
- 成交量分析（权重40%）
- 横盘突破识别
- 量价关系分析

## 📈 功能模块概览

### 🎯 核心功能
1. **股票池管理** - 持仓和潜在股票的完整生命周期管理
2. **AI策略分析** - 基于AI的投资策略生成和建议
3. **股票筛选** - 多维度股票筛选算法和可视化展示
4. **实时聊天** - 支持自然语言的股票查询和分析
5. **深度分析** - 专业的技术分析和量化评分

### 🤖 AI能力
- **自然语言处理**：理解用户的股票投资问题
- **智能数据检索**：自动获取相关股票数据
- **策略生成**：基于多维数据生成投资建议
- **风险评估**：动态风险等级评估和预警

### 📊 数据处理
- **实时行情数据**：集成AkShare获取实时股价
- **历史数据分析**：支持历史数据回测和分析
- **技术指标计算**：RSI、MACD、BOLL等技术指标
- **量化评分**：综合评分和投资等级划分
