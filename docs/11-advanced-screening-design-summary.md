## 二、核心策略体系设计

### 2.1 日线级策略（15个）

#### A. 基础过滤策略
1. **低价股过滤**
   - 股价 < 6元 → 剔除
   - 避免垃圾股和退市风险

2. **高位利好回避**
   - 累计涨幅 > 80% 且 出现利好新闻 → 剔除
   - 防止高位接盘

3. **均线偏离过远**
   - close/MA20 > 1.2 → 等待回调
   - 避免追高

4. **跳空三连阳回避**
   - 连续3日跳空缺口未回补 → 剔除
   - 防止短期过热

5. **换手率过高**
   - turnover > 40% 且 非新股 → 剔除
   - 避免过度投机

#### B. 积极信号策略
6. **量比选股**
   - 量比<0.5 且 创新高 → 买入信号（缩量新高）
   - 涨停且量比<1 → 次日高概率涨停
   - 突破20日均线后缩量回调 → 买入机会

7. **量价关系**
   - 缩量上涨 → 强势
   - 缩量下跌 → 仍弱
   - 放量滞涨 → 头部信号

8. **趋势跟随**
   - 5日均线放量突破 → 短线买入
   - 20日均线放量突破 → 中线买入
   - 跌破均线 → 卖出

9. **低位缺口策略**
   - 低位向上缺口 → 持有
   - 尾盘跳水 → 次日看涨
   - 趋势股（10/20日均线向上）→ 持股不做T

#### C. 风控策略
10. **持股数量控制**
    - 系统限制持仓 ≤ 3只

11. **大赚后空仓**
    - 单笔浮盈 > 50% → 建议部分止盈

### 2.2 分时级策略（4个）

1. **动态止盈止损**
   - 盈利≥15%，回落至10% → 止盈
   - 亏损≥5% → 止损

2. **追龙头首板**
   - 大盘放量上行 + 个股涨停板龙头 → 允许追入

3. **分时图短线出货点**
   - 白黄线乖离急拉 + 技术指标超买 → 卖出

4. **买分歧卖一致**
   - 连板股炸板后次日高开 → 买点
   - 超过3日不反包 → 放弃
