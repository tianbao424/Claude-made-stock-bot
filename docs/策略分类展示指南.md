## 🔧 功能特性

### 📋 分组折叠展示
- **默认展开** - 基础过滤分组默认展开
- **点击切换** - 点击分组头部可折叠/展开
- **状态记忆** - 记住用户的展开偏好

### 🎯 一键应用策略
- **应用按钮** - 每个策略卡片都有应用按钮
- **状态反馈** - 应用后显示"已选"状态
- **参数透传** - 直接将策略参数传递给筛选引擎

### 📊 性能指标展示
- **准确率** - 历史信号的正确率
- **信号数** - 历史产生的信号总数
- **胜率** - 盈利交易占比

### 🏷️ 智能标签系统
每个策略都有相关标签，便于理解策略特点：
- **功能标签**: 风险控制、趋势跟随、量价分析等
- **市场标签**: 强势股、控盘股、爆发股等
- **技术标签**: 均线系统、技术指标、形态识别等

## 🚀 操作流程

### 3步快速开始
1. **选择分类** - 点击感兴趣的策略分类
2. **浏览策略** - 查看各策略的描述和性能
3. **应用策略** - 点击"应用"按钮开始筛选

### ⚙️ 高级操作
- **编辑策略** - 点击编辑按钮修改策略参数
- **删除策略** - 删除自定义的策略预设
- **组合应用** - 同时应用多个策略进行综合筛选
