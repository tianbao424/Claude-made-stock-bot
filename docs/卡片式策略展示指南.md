## 🚀 快速模板功能

### 📋 4种预设组合

#### 1. 🛡️ 稳健防守型
- **特点**: 注重风险控制
- **适合**: 保守投资者
- **包含策略**: 
  - 低价股过滤 + 均线偏离检测
  - 换手率监控 + 黄金交叉
  - AI智能决策

#### 2. 🚀 激进进攻型  
- **特点**: 追求高收益
- **适合**: 激进投资者
- **包含策略**:
  - 智能量比分析 + 动能趋势分析
  - 突破形态猎手 + AI智能决策

#### 3. 📊 技术分析型
- **特点**: 基于技术指标
- **适合**: 技术派投资者
- **包含策略**:
  - 黄金交叉 + 动能分析 + 支撑阻力
  - 突破猎手 + 量价形态大师

#### 4. 💎 价值发现型
- **特点**: 挖掘价值机会  
- **适合**: 价值投资者
- **包含策略**:
  - 低价过滤 + 底部发现
  - 量能追踪 + 反转识别

## 🔍 智能筛选功能

### 📊 筛选维度

#### 1. 🔍 搜索功能
- **策略名称搜索** - 输入关键词快速定位
- **标签搜索** - 搜索"风险控制"、"技术指标"等
- **描述搜索** - 搜索策略功能描述

#### 2. 📁 分类筛选
- **全部分类** - 显示所有16个策略
- **基础过滤** - 5个基础策略
- **量价关系** - 4个量价策略
- **趋势跟随** - 3个趋势策略
- **技术形态** - 3个形态策略
- **综合判断** - 1个AI策略

#### 3. 🎯 难度筛选
- **基础级** - 新手友好，易于理解
- **中级** - 需要一定技术基础
- **高级** - 专业级策略，复杂算法

#### 4. 📊 排序方式
- **按准确率** - 性能优先排序
- **按信号数** - 活跃度排序
- **按名称** - 字母顺序排序

## 💡 使用技巧

### 🎯 选择策略组合建议

#### 新手推荐 (3-5个策略)
```
🛡️ 低价股过滤 + 🛡️ 均线偏离检测 + 📈 黄金交叉 + 🧠 AI决策
```

#### 进阶组合 (5-8个策略)  
```
基础过滤(2个) + 量价关系(2个) + 趋势跟随(2个) + AI决策(1个)
```

#### 专业组合 (8-12个策略)
```
全方位覆盖，多维度分析，适合专业投资者
```

### 📊 性能参考指标

#### 🎯 关键指标解读
- **准确率**: 历史信号的正确率
- **胜率**: 盈利交易的比例  
- **信号数**: 历史产生的信号数量
- **评分**: 综合表现评分(0-100)

#### 🔍 选择原则
1. **准确率>80%** - 优先选择
2. **胜率>75%** - 盈利能力强
3. **信号数适中** - 既不过于频繁也不过于稀少
4. **评分>70** - 综合表现良好
