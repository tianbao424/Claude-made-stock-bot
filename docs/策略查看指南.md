# 📖 策略查看指南

## 🚀 快速开始

### 1. 启动应用
```bash
# 后端服务 (端口8001)
cd backend && python main.py

# 前端服务 (端口3001) 
cd frontend && npm run dev
```

### 2. 访问策略页面
1. 打开浏览器访问: **http://localhost:3001**
2. 在左侧菜单中点击: **"高级策略"** (🧠图标)

## 🎯 16个策略详解

### 🛡️ 基础过滤策略 (5个)
1. **低价股过滤** - 过滤6元以下垃圾股
2. **高位利好过滤** - 避免高位出货陷阱  
3. **均线偏离过滤** - 避免偏离均线过远
4. **跳空高开过滤** - 识别连续跳空风险
5. **换手率异常过滤** - 过滤异常换手

### 📊 量价关系策略 (4个)  
6. **量比分析策略** - 多维度量比分析
7. **量价关系策略** - 量价配合协调性
8. **量能趋势分析** - 资金流向追踪
9. **低量低价策略** - 底部机会识别

### 📈 趋势跟随策略 (3个)
10. **均线金叉策略** - 金叉和多头排列
11. **趋势动能策略** - RSI/KDJ/MACD综合
12. **趋势反转策略** - 反转时机识别

### 📄 技术形态策略 (3个)
13. **支撑阻力策略** - 关键位买卖信号
14. **突破策略** - 各种突破形态识别  
15. **量价配合形态** - 深度量价分析

### 🧠 综合判断策略 (1个)
16. **综合分析策略** - 智能多维度决策

## ⚙️ 策略配置操作

### 启用/禁用策略
- 点击策略卡片左侧的 **复选框** ☑️
- 选中的策略会高亮显示

### 配置策略参数  
1. 点击策略卡片右侧的 **设置图标** ⚙️
2. 在弹出的参数配置窗口中调整参数
3. 点击 **"保存配置"** 应用更改

### 使用预设模板
1. 切换到 **"预设模板"** 标签页
2. 选择合适的模板点击 **"应用模板"**
   - **稳健型** - 风险控制优先
   - **激进型** - 收益最大化
   - **技术型** - 技术指标驱动

### 开始筛选
1. 配置好策略后点击右上角 **"开始筛选"** 按钮
2. 系统将使用选中的策略进行股票筛选
3. 筛选结果会显示每个策略的评分和综合建议

## 📊 策略性能查看

切换到 **"性能监控"** 标签页可以查看：
- 策略历史准确率
- 平均评分表现  
- 信号数量统计
- 推荐成功率

## 💡 使用技巧

1. **新手建议**: 先使用"稳健型"预设模板
2. **进阶用户**: 根据市场环境调整策略组合
3. **参数调优**: 根据历史表现微调策略参数
4. **组合使用**: 建议同时启用3-5个不同类型的策略

## 🔧 技术支持

如有问题请检查：
1. 后端服务是否正常运行 (http://localhost:8001/health)
2. 前端服务是否正常运行 (http://localhost:3001)
3. 策略注册是否成功 (查看后端日志)
