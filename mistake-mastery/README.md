# 学透 · 北京初三数理错题闭环（家庭自用 · v0.1 本地版）

> **错一题，透一类。**
> 给我家初三孩子用的数学、物理错题工具：拍照收集 → 擦除重做 → 举一反三 → 分步讲解 → 考前打印 → 循环迭代，**直到学透**。

**状态**：v0.1 本地版已实现（拍照识别、擦除、打印、错题本、GitHub 同步），另外提前做了**题库导入**（真题和区统考 PDF，录入时自动带官方答案）和**知识点整理**（每个考点的掌握度，找出掌握死角，薄弱知识点按孩子的错题生成讲解）。题库导入已在家长电脑上用真实模型（DeepSeek）验证过一份物理期中卷；拍照识别、擦除接口、讲解还待用真实接口验证 → [安装与使用](SETUP.md)
**性质**：**家庭自用，非商业**。只有一个家庭使用，不对外提供服务

> ⚠️ **本仓库是公开的**。孩子的任何数据（区、学校、照片、错题、评测题）都只存在**私有数据仓库**和服务器上，不进本仓库。
**范围**：北京 · 初三 · 数学 + 物理 · 2026–2027 学年（2027 年 6 月中考）

## 一页纸

| | |
|---|---|
| **谁用** | 孩子在纸上作答；家长拿手机拍照、打印、回填，也负责维护这套系统 |
| **解决什么** | 抄错题太耗时；原卷写满了没法重做；换个数又错；考前找不全；同一个坑反复掉 |
| **核心机制** | 每道错题都要过**三道关**：① 原题关（空白卷原位重做）→ ② 变式关（5 道变式做对 ≥ 4 道，综合题必须对）→ ③ 时间关（间隔 7 天以上复习仍然做对）。三关都过 = **✅ 学透**；任何一关失败 → **回炉，轮次 +1** |
| **为什么自己做** | 现成工具各管一段，没有"学透"判定和回炉机制；也不贴合北京中考题型（数学第 16、26、27、28 题，物理实验探究和科普阅读） |
| **形态** | 云服务器（推荐香港轻量服务器）上的网页应用；手机在任何网络下通过 HTTPS 访问，可以"添加到主屏幕" |
| **数据** | 正本存在 **GitHub 私有仓库**（表数据为 JSONL 文本 + 卷子图片，带完整历史）；服务器上只是工作副本，随时可以从仓库恢复 |
| **技术** | FastAPI + SQLite（工作副本）+ Caddy（HTTPS）；React 网页；云端去手写和切题接口；通义千问、豆包等国内模型（两家交叉校验）；HTML + Chromium 排版生成 PDF |
| **花费** | 约**每月 40–85 元**：服务器和域名约 35–65 元，AI 和擦除接口约 5–20 元，GitHub 私有仓库免费 |
| **节奏** | 本周试水 → v0.1 赶上期中卷子发回（11 月上旬）→ v0.2 举一反三（11 月底）→ v0.3 讲解和考前打印赶上期末（12 月底）→ v0.4 寒假 |

```mermaid
flowchart LR
    A["① 拍照收集"] --> B["② 擦除 · 原位重做"]
    B -->|✓| C["③ 5 道变式"]
    B -->|✗| D["④ AI 分步讲解"]
    C -->|达标| E["间隔复习"]
    C -->|未达标| D --> C
    E -->|✓| M(["✅ 学透"])
    E -->|✗ 回炉| A
    F["⑤ 考前集中打印"] -->|✗ 回炉| A
```

## 🔶 开工前需要确定的事

**已确定**：
- **先做本地版**：程序跑在家里的电脑上，手机连家里 Wi-Fi 用浏览器访问；
- **数据存 GitHub 私有仓库**（本地版就开始同步）；
- 公网访问（香港服务器，下面 D1、D2）等本地版用顺了再做，代码不用改，换个地方部署即可。

| # | 事项 | 推荐 | 备选 |
|---|------|------|------|
| **D1** | 服务器放在哪里 | **香港轻量应用服务器**（阿里云或腾讯云，2 核 2G）：不需要 ICP 备案，访问 GitHub 稳定 | 大陆服务器：要先办个人 ICP 备案（一到几周），而且推送 GitHub 不稳定（见 [03 §3](docs/03-system-architecture.md)） |
| **D2** | 域名 | 买一个便宜域名，解析到服务器，用来申请 HTTPS 证书 | — |
| **D3** | 私有数据仓库 | 在你的 GitHub 账号下新建私有仓库（如 `xuetou-data`）；账号开启两步验证 | — |
| **D4** | 开通哪些 AI 接口 | **通义千问（阿里云百炼）+ 豆包（火山方舟）**，两家做交叉校验 | DeepSeek、智谱、Kimi 作备用 |
| **D5** | 擦除接口 | 用 10 页真实卷子在**百度、有道、TextIn** 上试过再定 | 效果都不理想时，用夸克扫描王处理后上传 |
| **D6** | 家里的打印机 | **A4 打印机**（原位重做依赖 A4；黑白即可） | 没有的话，PDF 发到单位或打印店打印 |
| **D7** | 讲解在哪个设备上用 | **平板**（字大、横屏看图方便） | 家长手机 |
| **D8** | 孩子的基本信息 | 所在区、教材版本、本学期考试日期——**在系统里填写，不要写进本仓库** | 见 [01 §2.2](docs/01-product-requirements.md) |

## 要靠试水来验证的假设

1. 云端去手写接口在孩子的卷子上（几何辅助线、电路图、红笔批改）大多数页面不需要手动修补。
2. "程序化出题 + 两家模型交叉校验"出的变式题，家长抽查时基本挑不出错。
3. 家长每周花 10–15 分钟拍照和打印，就能支撑孩子每天约 20 分钟的纸面练习。
4. 孩子认可"三道关"的说法，愿意按每日学透单去练。
5. 香港服务器调用国内 AI 和擦除接口、推送 GitHub、手机上传照片，速度都可以接受。
