# 学透 · 北京初三数理错题闭环（家庭自用 · 设计阶段）

> **错一题，透一类。**
> 给我家初三孩子用的数学、物理错题工具：拍照收集 → 擦除重做 → 举一反三 → 分步讲解 → 考前打印 → 循环迭代，**直到学透**。

**状态**：🎨 设计稿 v0.2（2026-10-13），尚未开发
**性质**：**家庭自用，非商业**。只有一个家庭使用，不对外提供服务
**范围**：北京 · 初三 · 数学 + 物理 · 2026–2027 学年（2027 年 6 月中考）

---

## 一页纸

| | |
|---|---|
| **谁用** | 孩子在纸上作答；家长拿手机拍照、打印、回填，也负责维护这套系统 |
| **解决什么** | 抄错题太耗时；原卷写满了没法重做；换个数又错；考前找不全；同一个坑反复掉 |
| **核心机制** | 每道错题都要过**三道关**：① 原题关（空白卷原位重做）→ ② 变式关（5 道变式做对 ≥ 4 道，综合题必须对）→ ③ 时间关（间隔 7 天以上复习仍然做对）。三关都过 = **✅ 学透**；任何一关失败 → **回炉，轮次 +1** |
| **为什么自己做** | 现成工具各管一段，没有"学透"判定和回炉机制；也不贴合北京中考题型（数学第 16、26、27、28 题，物理实验探究和科普阅读） |
| **形态** | 家里常开的电脑上运行的网页应用；手机浏览器访问，可以"添加到主屏幕" |
| **技术** | FastAPI + SQLite + 本地文件夹；React 网页；云端去手写和切题接口；通义千问、豆包等国内模型（两家交叉校验）；HTML + Chromium 排版生成 PDF |
| **花费** | AI 和擦除接口估计**每月 5–20 元**；硬件用家里现有的电脑和打印机 |
| **节奏** | 本周试水 → v0.1 赶上期中卷子发回（11 月上旬）→ v0.2 举一反三（11 月底）→ v0.3 讲解和考前打印赶上期末（12 月底）→ v0.4 寒假 |

```mermaid
flowchart LR
    A["① 拍照收集"] --> B["② 擦除 · 原位重做"]
    B -->|✓| C["③ 5 道变式"]
    B -->|✗| D["④ AI 分步讲解"]
    C -->|达标| E["间隔复习"]
    C -->|未达标| D --> C
    E -->|✓| M(["✅ 学透"])
    E -->|✗ 回炉| A
    F["⑤ 考前集中打印"] -->|✗ 回炉| A
```

> **工具做好之前**：第 ② 步可以先用夸克扫描王的"试卷去手写"打印空白卷，期中复习不用等（见 [08 §4](docs/08-privacy-vendors-and-tools.md)）。

## 🔶 开工前需要确定的事

| # | 事项 | 推荐 | 备选 |
|---|------|------|------|
| **D1** | 系统跑在哪台机器上 | **家里常开的电脑、Mac mini 或 NAS**；在外面要用时装 Tailscale | 平时用的笔记本（开着才能用）；云服务器 |
| **D2** | 家里的打印机 | **A4 打印机**（原位重做依赖 A4；黑白即可） | 没有的话，PDF 发到单位或打印店打印 |
| **D3** | 开通哪些 AI 接口 | **通义千问（阿里云百炼）+ 豆包（火山方舟）**，两家做交叉校验 | DeepSeek、智谱、Kimi 作备用 |
| **D4** | 擦除接口 | 本周用 10 页真实卷子在**百度、有道、TextIn** 上试过再定 | 效果都不理想时，用夸克扫描王处理后上传 |
| **D5** | 孩子的基本信息 | 所在区、数学和物理教材版本、本学期考试日期 | 见 [01 §2.2](docs/01-product-requirements.md) |
| **D6** | 讲解在哪个设备上用 | **平板**（字大、横屏看图方便） | 家长手机 |

## 要靠试水来验证的假设

1. 云端去手写接口在孩子的卷子上（几何辅助线、电路图、红笔批改）大多数页面不需要手动修补。
2. "程序化出题 + 两家模型交叉校验"出的变式题，家长抽查时基本挑不出错。
3. 家长每周花 10–15 分钟拍照和打印，就能支撑孩子每天约 20 分钟的纸面练习。
4. 孩子认可"三道关"的说法，愿意按每日学透单去练。
