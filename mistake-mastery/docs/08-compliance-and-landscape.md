## 1. 合规

本产品同时是**面向未成年人的应用**、**生成式 AI 应用**和**教育类应用**，三套规则叠加适用。

### 1.1 合规事项清单

### 1.2 隐私设计要点

| 要点 | 做法 |
|------|------|
| 账号模式 | 家长注册，孩子只是家长账号下的档案；不给孩子单独开设可登录的账号（学生模式由家长开启） |
| 最小化 | 昵称代替真名；学校、区县选填（区县用于预填教材版本和考试日历） |
| 去标识 | 卷头（姓名、班级、学号）检测后打码，再送给第三方模型；向模型发送的请求中只带匿名哈希 |
| 训练数据 | 用户修补的擦除蒙版、更正后的分类，**单独征得同意**才能用于模型改进（`consents.scopes` 中的 `training_data`） |
| 保留期限 | 原图默认保存到孩子毕业后 12 个月（可以设置）；注销时 15 日内物理删除 |
| 供应商 | 签订数据处理协议：仅限处理目的，禁止用于训练，按约定删除 |

### 1.3 待律师确认的事项

1. 北京市网信办登记的具体流程和时长。
2. 收费会员是否需要 ICP 经营许可证（B25）。
3. 本产品是否会被认定为"线上学科类培训"（预计不会：我们不提供课程，也没有真人教师）。
4. 《拟人化互动服务管理办法》对讲解功能的适用性。
5. 《标识办法》关于导出文件标识、"无标识版本"的条款原文。

## 3. 竞品

### 3.1 竞品一览

| 类别 | 代表产品 | 核心能力 | 商业模式 | 已知短板 |
|------|----------|----------|----------|----------|
| 错题打印机 | 作业帮喵喵机、小猿、得力、汉印、启锐 | 拍照 → 搜题 → 热敏打印；接入大题库，可推同类题 | 硬件约 100–300 元 + App 会员 | **热敏纸会褪色、幅面窄**，没法原位重做，也不适合装订；组卷版式和分类结构固定 |

### 3.2 我们的差异化

| 维度 | 竞品普遍做法 | 学透 |
|------|-------------|------|
| 终点 | 收集到了、打印出来了 | **三关判定"学透"**，每道错题都有状态和轮次 |
| 重做 | 小票纸打印题目截图 | **A4 擦除还原，原位重做**，像重新考一次 |
| 举一反三 | 题库里的相似题（按文本相似度） | **5 级变式阶梯** + 程序化出题 + 交叉校验，针对"方法"而不是"字面" |
| 讲解 | 直接给答案和解析 | 苏格拉底式五步讲解 + 诊断式讲解（定位具体错在哪一步） |
| 本地化 | 全国通用 | **北京中考题位**（数学第 16、26、27、28 题，物理实验探究、科普阅读）、北京教材版本、各区考试日历 |
| 回填 | 很少有 | 二维码回传 + AI 批改，自动驱动复习调度 |
| 可信度 | 投诉集中在判题和解析出错 | 拿不准就不出；交叉校验 + 每周人工抽检 |

**风险提示**：作业帮、夸克等头部厂商有能力快速跟进单点功能（比如去手写）。我们的壁垒在**闭环机制 + 北京教研深度 + 变式质量**，这三者都需要持续积累，单点功能很难复制出来。
