# 01 · 产品需求文档（PRD）

**产品代号**：mistake-mastery（暂定名「学透」）
**一句话定位**：面向北京初三学生的数学、物理错题闭环工具，目标是把错题**学透**，不只是收集起来。
**文档状态**：设计稿 v0.1（2026-10-13），尚未评审

---

## 1. 背景与机会

### 1.1 初三学生的错题困境

| 环节 | 现状 | 代价 |
|------|------|------|
| 收集 | 手抄错题本，或剪贴、拍照存进相册 | 抄一道几何综合题要 10–15 分钟，抄完就没时间做了 |
| 重做 | 原卷上已经写满答案和红笔批注，没法直接重做 | 只能"看懂"答案，"看懂"了不等于"会做" |
| 迁移 | 换个数、换个情境又错 | 错的是"一类题"，练的却只有"一道题" |
| 求助 | 不会的题要等第二天问老师，或者家长也讲不清 | 卡点越积越多 |
| 复习 | 考前在一摞卷子里翻错题 | 找不全，优先级也排不出来 |
| 反复 | 复习时又错了，但没人记录 | 同一个坑反复掉 |

### 1.2 现有产品的空白

市面上的错题打印机、学习机错题本和拍照搜题 App，基本解决了**收集**和**打印**（详见 [08-合规与竞品](08-compliance-and-landscape.md)）。缺的是两件事：

1. **"学透"没有判定标准**：错题收进去以后没有状态，不知道哪道已经掌握、哪道还会再错。
2. **没有针对北京中考做本地化**：北京中考数学的新定义题、几何综合题，物理的科普阅读题、实验探究题，命题风格独特，通用题库的变式题针对性不足。

### 1.3 我们的切入点

> **错一题，透一类。**
> 以"学透"为终点设计闭环：每道错题都有状态、有轮次、有判定标准，直到真正掌握。

## 2. 目标用户

### 2.1 用户角色

| 角色 | 在产品中的角色 | 核心诉求 | 关键约束 |
|------|----------------|----------|----------|
| **初三学生**（14–15 岁） | 做题的人，主要在**纸上**完成 | 少花时间、练得有效、不会的能马上弄懂 | 很多学校和家庭管控手机；晚上 22:00 前作业都做不完 |
| **家长** | **操作者 + 付费者**，负责拍照、打印、看进度 | 省心、看得到孩子进步、知道薄弱点在哪 | 时间碎片化；家里通常有打印机；自己未必能讲清楚题 |

> **关键洞察**：在初三阶段，**家长拿手机，孩子拿笔**。产品的数字化部分主要由家长在手机上操作，学习本身尽量回到纸面。这和北京中考仍是纸笔考试的现实一致。

### 2.2 典型画像

- **小雨**：海淀区初三学生。数学 80–90 分（满分 100），第 27 题几何综合和第 28 题新定义题经常丢分；物理电学计算和实验探究题反复出错。每周有 2–3 张周测卷，每月一次月考。
- **小雨妈妈**：双职工，晚上 21:00 后才有时间。家里有一台喷墨打印机。以前试过手抄错题本，坚持了两周。

### 2.3 核心使用场景

| 场景 | 频率 | 主要操作 | 对应步骤 |
|------|------|----------|----------|
| 周测或月考卷子发回 | 每周 2–3 次 | 整页批量拍照，自动挑出错题 | ① ② |
| 日常作业中的错题 | 每天 | 单题拍照 | ① |
| 周末集中巩固 | 每周 | 打印变式练习单 | ③ |
| 孩子遇到不会的题 | 随时 | 拍照请 AI 分步讲解 | ④ |
| 期中、期末、一模、二模前 | 每学期 3–4 次 | 筛选错题，一键排版打印 | ⑤ |
| 复习中又做错 | 持续 | 回填结果，自动回炉 | ⑥ |

## 3. 产品原则

1. **纸笔优先（Paper-first）**：输入是纸，输出也是纸，手机只是中枢。孩子在纸上的作答时间要多于在屏幕前的时间。
2. **以"学透"为终点，而不是以"收集"为终点**：每道错题都有明确状态，直到达到"学透"标准（见 §6）。
3. **控量，靠优先级驱动**：初三时间极其宝贵。系统每天只推最该练的那几道题，宁少勿滥。
4. **AI 必须可信**：AI 生成的答案、变式题、讲解**必须经过校验**（双模型交叉解题 + 符号计算核验），并做显著标识。拿不准的题宁可不出。
5. **家长省心**：一次录入不超过 3 步，一次打印只需 1 步。
6. **北京本地化**：知识点体系、题型、难度和命题风格对齐北京中考与北京各区模拟考（见 [07-北京课程与考情](07-beijing-curriculum.md)）。
7. **守住合规底线**：不做"拍照出答案"（双减红线），讲解以引导为主；只调用境内已备案的大模型；AI 生成的内容一律标识（见 [08-合规](08-compliance-and-landscape.md)）。

## 4. 核心闭环

```mermaid
flowchart LR
    A["① 拍照收集<br/>识别·分类·归档"] --> B["② 擦除手写<br/>打印空白卷，原位重做"]
    B -->|重做正确| C["③ 举一反三<br/>5 道变式题"]
    B -->|重做仍错| D["④ AI 分步讲解"]
    C -->|变式达标| E["间隔复习<br/>（系统调度）"]
    C -->|变式未达标| D
    D --> C
    E -->|复习正确| M(["✅ 已学透"])
    E -->|复习做错| A
    F["⑤ 考前集中打印<br/>筛选·排版·打印"] -->|考前重做出错| A
    M -.->|考前打印也会选入| F
```

> 第 ⑥ 步"循环迭代"不是一个单独的页面，而是贯穿整个闭环的**回炉机制**：任何环节再次做错，这道题都回到 ①，开始新一轮（轮次 +1），并继承之前的全部历史。

## 5. 功能需求

优先级：**P0** = MVP 必须有；**P1** = MVP 之后第一批；**P2** = 远期。

### F1 · 拍照收集：AI 自动识别、分类、归档

**用户故事**：作为家长，我希望把发回来的卷子拍一下，系统就自动挑出错题、认出题目并归到对应知识点，不用我手动输入。

| # | 功能点 | 说明 | 优先级 |
|---|--------|------|--------|
| F1.1 | 单题拍照 | 拍照并框选一道题；支持从相册导入 | P0 |
| F1.2 | 整页拍照 + 自动切题 | 一张照片含多道题时，自动切分成独立题目 | P0 |
| F1.3 | 连拍多页 | 一份试卷多页连续拍摄，作为同一份"来源卷"归档 | P0 |
| F1.4 | 拍摄质量引导 | 实时提示模糊、反光、倾斜、阴影；自动透视矫正、去阴影 | P0 |
| F1.5 | 红笔批改识别，自动预选错题 | 识别老师的 ✗、半对、扣分标记，预先勾选错题，家长只需确认 | P1 |
| F1.6 | 题目结构化识别 | 题干、选项、小问、图形（几何图、电路图、实物图）、学生作答、老师批注分层提取；公式转为 LaTeX | P0 |
| F1.7 | 自动分类 | 学科、章节、**知识点（多标签）**、题型、难度、对应的北京中考题位（如"类第 28 题新定义"） | P0 |
| F1.8 | 正确答案获取 | 优先采用卷面上老师给出的答案或答案页照片，其次由 AI 解答。AI 解答须经校验，并标注置信度 | P0 |
| F1.9 | 错因标注 | AI 对比学生作答与正确答案，给出错因建议（如"计算错误""审题失误"）；一键确认或修改 | P0 |
| F1.10 | 来源标注 | 作业、周测、月考、期中、期末、一模、二模，以及考试名称和日期；可识别卷头（如"2026 海淀区九年级期中"） | P0 |
| F1.11 | 去重合并 | 同一道题重复录入时自动合并，错误次数 +1 | P0 |
| F1.12 | 批量确认页 | 处理完成后，用卡片列表展示所有识别出的错题，可逐个修改或一键全部确认 | P0 |

**验收标准（MVP）**
- 整页切题准确率 ≥ 95%（以人工标注为准）
- 知识点 Top-3 命中率 ≥ 90%，Top-1 ≥ 75%
- 单页处理耗时 P90 ≤ 20 秒（异步处理，用户可以离开页面）
- 从拍完照到确认归档，家长的操作步骤 ≤ 3 步

### F2 · 一键擦除手写：打印空白卷，原位重做

**用户故事**：作为学生，我希望拿到一张和原卷一模一样、但没有任何笔迹的卷子，在原来的位置上重新做一遍，就像重新考一次。

| # | 功能点 | 说明 | 优先级 |
|---|--------|------|--------|
| F2.1 | 整页擦除（原卷还原） | 去除所有手写笔迹（黑笔、铅笔、红笔批改、涂改），保留印刷内容与原始版式 | P0 |
| F2.2 | 图形内擦除 | **几何图上手画的辅助线、标注**和电路图上的涂画也要擦掉，同时不能伤到印刷线条 | P0 |
| F2.3 | 擦除预览与修补 | 前后对比滑块；"补擦"画笔清理残留笔迹，"恢复"画笔找回误擦的印刷内容 | P0 |
| F2.4 | 只保留错题（错题重做单） | 只输出选中的错题，每题保持原貌，作答区大小参照原卷 | P0 |
| F2.5 | 纸张适配 | 原卷常见 8K、B4、A3 双栏等大幅面，可等比缩放到 A4，或按 A3 原尺寸输出 | P0 |
| F2.6 | 回传码 | 每页印上二维码与题号锚点，做完拍照回传时自动对应到每一道题（见 F6.3） | P0 |
| F2.7 | 打印方式 | 生成 PDF，可直接调用系统打印（AirPrint、Mopria），或分享到电脑打印 | P0 |
| F2.8 | 错题打印机适配 | 适配窄幅热敏打印机（57/80/110mm） | P2 |

**验收标准（MVP）**
- 擦除后无需手动修补的页面比例 ≥ 85%
- 印刷内容误擦率（按字符计）≤ 0.5%
- 单页擦除耗时 P90 ≤ 15 秒

### F3 · 举一反三：AI 出 5 道变式题，练到彻底掌握

**用户故事**：作为学生，原题重做对了以后，我希望再做几道"换汤不换药"的题，确认自己真的会了，而不是只记住了这道题的答案。

**变式阶梯（每组 5 题）**

| 题号 | 层级 | 变式手法 | 目的 |
|------|------|----------|------|
| 1 | 同构巩固 | 结构不变，只换数据或字母 | 确认方法掌握 |
| 2 | 同构巩固 | 换表述方式或已知条件的给出形式 | 排除"背答案" |
| 3 | 迁移变式 | 换情境（如滑轮换成杠杆，三角形换成四边形） | 方法迁移 |
| 4 | 迁移变式 | 改设问方向（正向求解改为逆向求参、存在性问题等） | 理解深化 |
| 5 | 综合提升 | 与关联知识点综合，按北京中考题风格命制 | 实战对接 |

| # | 功能点 | 说明 | 优先级 |
|---|--------|------|--------|
| F3.1 | 生成 5 道变式 | 按上表阶梯生成，难度围绕原题上下浮动 | P0 |
| F3.2 | 正确性校验 | 双模型独立解题、答案一致性比对、符号或数值计算核验（sympy）、题目良定性检查（有唯一解、数据合理、不超纲）；**未通过校验的题不下发** | P0 |
| F3.3 | 题库优先 | 若题库中已有同知识点的已审核题（北京真题、模拟题），优先选用；AI 生成只用来补足 | P1 |
| F3.4 | 图形题变式 | MVP：复用原图并修改标注或数据，或降级为无图变式；后续：由程序化绘图（几何、电路）生成新图 | P0 降级 / P1 完整 |
| F3.5 | 作答方式 | 打印成变式练习单（答案页单独打印，或扫码查看）；也可在线逐题作答 | P0 |
| F3.6 | 掌握判定与追加 | 5 题做对 ≥ 4 题且第 5 题（综合题）必须做对，判为"变式达标"；否则进入 F4 讲解，再针对做错的层级**追加 3 道** | P0 |
| F3.7 | 题目反馈 | 每道变式都有"题目有问题"按钮；被反馈的题下线并进入人工复核 | P0 |

**验收标准（MVP）**
- 下发的变式题答案错误率 < 1%（每周人工抽检）
- 题目超纲率 < 2%
- 一组 5 题的生成耗时 P90 ≤ 90 秒（异步，完成后通知）

### F4 · AI 分步讲解：拍照让 AI 一步步讲清楚

**用户故事**：作为学生，遇到还不会的题，我希望 AI 像老师一样一步步引导我想明白，而不是直接把答案甩给我。

| # | 功能点 | 说明 | 优先级 |
|---|--------|------|--------|
| F4.1 | 发起方式 | 从错题详情发起；从变式练习中发起；拍一道新题时，**先作为错题录入（孩子已经尝试过）再讲解**，不提供"拍照直接出答案" | P0 |
| F4.2 | 分步引导 | 按"审题（已知、所求）→ 联想考点与方法 → 关键一步提示 → 完整过程 → 方法总结与易错点"五步逐步展开，每一步都要点击才显示下一步 | P0 |
| F4.3 | 追问 | 每一步都可以追问"这一步为什么"，或说"我还是不懂"，AI 换一种讲法 | P0 |
| F4.4 | 诊断式讲解 | 拍下孩子自己的解题过程，AI 定位**具体错在哪一步**，再从那一步开始讲 | P1 |
| F4.5 | 规范作答指导 | 结合北京中考评分标准讲步骤分：数学解答题的关键步骤，物理计算题"公式—代入—结果—单位" | P0 |
| F4.6 | 公式与图形渲染 | LaTeX 渲染；在图上标注辅助线、受力分析、电流方向 | P0 渲染 / P1 标注 |
| F4.7 | 置信度兜底 | AI 校验不通过时，明确提示"这道题 AI 把握不足，建议请教老师"，不硬讲 | P0 |
| F4.8 | 语音讲解 | TTS 朗读，适合家长不在身边时使用 | P2 |

### F5 · 考前集中打印：筛选整学期错题，一键排版打印

**用户故事**：作为家长，期中考试前，我希望一键打印出本学期这次考试范围内、孩子还没掌握的错题，排版整齐，直接给孩子做。

| # | 功能点 | 说明 | 优先级 |
|---|--------|------|--------|
| F5.1 | 多维筛选 | 时间范围、学科、章节或知识点、错因、状态（未学透、反复错、全部）、错误次数 ≥ N、来源、难度 | P0 |
| F5.2 | 智能预设 | "期中冲刺（按考试范围）""一模前高频错""反复错 TOP 30""本月新错题" | P0 |
| F5.3 | 排版选项 | 纸张（A4/B5/A3）、单栏或双栏、作答留白（按原卷大小、固定高度或不留）、是否附答案页、是否附变式题、按知识点分节并生成目录 | P0 |
| F5.4 | 排版质量 | 一道题不跨页；图文不分离；页眉含姓名、日期、范围；带页码和回传码 | P0 |
| F5.5 | 题量与时长预估 | 显示"共 32 题，约需 95 分钟"，并建议拆成几份 | P1 |
| F5.6 | 打印记录 | 保存每次打印的筛选条件和题目清单，可以重新打印 | P0 |

### F6 · 循环迭代：复习中又做错，回到步骤 ①

| # | 功能点 | 说明 | 优先级 |
|---|--------|------|--------|
| F6.1 | 结果回填（自评） | 在打印单对应的页面逐题勾选 ✓/✗/半对（对照答案页） | P0 |
| F6.2 | 回炉 | 任何环节做错（重做、变式、复习、考前打印），这道题回到 ①，轮次 +1，状态重置为"待重做"，历史完整保留 | P0 |
| F6.3 | 回传扫描，AI 批改 | 拍下做完的打印单，靠二维码定位每道题，AI 自动判对错 | P1 |
| F6.4 | 错题旅程 | 每道错题一条时间线：第 1 轮录入 → 重做 ✗ → 讲解 → 变式 4/5 → 复习 ✓ → 第 2 轮…… | P0 |
| F6.5 | 每日学透单 | 每天自动生成一页 A4：今日重做 + 变式 + 到期复习，控制在约 20 分钟 | P1 |
| F6.6 | 考试日历驱动 | 录入期中、期末、一模、二模日期，系统在考前压缩复习间隔，确保考试范围内的错题都复习过一遍 | P1 |

## 6. "学透"的定义

一道错题从录入到"学透"，必须依次通过**三道关**：

| 关卡 | 判定条件 | 证明的是 |
|------|----------|----------|
| ① 原题关 | 在空白卷上原位重做正确 | 这道题会做了 |
| ② 变式关 | 5 道变式做对 ≥ 4 题，且综合题做对 | 这类题会做了 |
| ③ 时间关 | 间隔 ≥ 7 天后的复习题（原题或新变式）做对 | 过一段时间还会做 |

三关全部通过，状态变为 **✅ 已学透**。已学透的题仍会以低频率进入考前打印。任何一关失败都会触发回炉。完整状态机与调度算法见 [06-掌握度与复习算法](06-mastery-algorithm.md)。

## 7. MVP 范围

| 模块 | MVP（P0） | 后续（P1） | 远期（P2） |
|------|-----------|-----------|-----------|
| ① 收集 | 单题和整页拍照、切题、识别、分类、错因、归档、去重 | 红笔批改识别并自动预选错题 | 北京真题题库匹配（直接拿到权威解析） |
| ② 擦除 | 整页擦除、错题重做单、修补工具、PDF 打印 | — | 错题打印机硬件 |
| ③ 变式 | 5 题阶梯 + 双重校验；图形题降级 | 题库优先、程序化绘图 | 自适应难度 |
| ④ 讲解 | 五步引导、追问、置信度兜底 | 诊断式讲解、图上标注 | 语音讲解 |
| ⑤ 考前打印 | 多维筛选、预设、排版 | 题量与时长预估 | 多孩子合并 |
| ⑥ 迭代 | 自评回填、回炉、错题旅程 | 回传扫描批改、每日学透单、考试日历 | — |
| 基础 | 账号、孩子档案、监护人同意、简版看板 | 家长周报、会员 | 教师/机构端 |

**MVP 学科范围**：数学 + 物理两科同时上线。MVP 阶段的知识点体系、题型和难度标定都只针对北京初三。

## 8. 成功指标

**北极星指标**：每个活跃学生每周"学透"的错题数。

| 类别 | 指标 | MVP 目标 |
|------|------|----------|
| 激活 | 注册后 7 天内完成首次录入的比例 | ≥ 60% |
| 闭环 | 录入的错题中进入"原题重做"的比例 | ≥ 50% |
| 闭环 | 重做后进入变式的比例 | ≥ 40% |
| 结果 | 录入 30 天内达到"已学透"的错题比例 | ≥ 25% |
| 结果 | 已学透错题的复错率（30 天内再次做错） | ≤ 15% |
| 质量 | 变式题被反馈有误的比例 | < 1% |
| 质量 | 擦除后无需修补的比例 | ≥ 85% |
| 留存 | 周留存（第 4 周） | ≥ 40% |

## 9. 商业模式（初步）

- **免费版**：拍照归档不限量；每月 10 页擦除、3 组变式、10 次讲解。
- **会员**（按月、按学期、按"初三全年"）：擦除、变式、讲解、考前打印不限量，另含每日学透单与家长周报。
- **单位成本控制**：识别结果按题缓存；变式优先从题库取；同一道题的变式和讲解在用户之间复用（只复用题目本身，不复用用户数据）。单用户月均 AI 成本目标见 [03-系统架构](03-system-architecture.md) §9。

## 10. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 识别 P90 ≤ 20 秒/页；擦除 P90 ≤ 15 秒/页；变式 P90 ≤ 90 秒/组；讲解首字延迟 ≤ 2 秒（流式输出） |
| 可用性 | 服务可用性 ≥ 99.5%；AI 供应商故障时自动切换到备用模型 |
| 隐私 | 最小化收集；不强制填写真实姓名和学校；照片中的姓名区域自动打码后再送给模型（见合规文档） |
| 数据驻留 | 全部数据存储在境内（北京地域） |
| 可访问性 | 大字号模式（方便家长）；打印件灰度友好（多数家用打印机只用黑白打印） |
