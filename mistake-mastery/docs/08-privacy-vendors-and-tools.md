> 资料截至 2026-10-13，来源为官方文件、厂商文档和媒体报道的检索摘要。**价格和接口细节以各平台控制台为准；涉及法规的内容是一般性说明，不是法律意见。** 可信度：高 / 中 / 低。

## 1. 自用场景下的规则边界

### 1.1 家庭自用时不涉及的事项

v0.1 设计稿按"面向公众的商业产品"列过一份合规清单（生成式 AI 登记、ICP 和小程序备案、教育 App 备案、等保、未成年人个人信息年度审计、双减相关的平台规则等）。**这些都针对"向公众提供服务"的运营者**。本项目只在自己家里使用，不向任何外部用户提供服务，所以都不需要办理。

例如，《生成式人工智能服务管理暂行办法》第二条规定，研发、应用生成式人工智能技术但未向境内公众提供服务的，不适用该办法【中】。

### 1.2 仍然要注意的事项

| 事项 | 做法 |
|------|------|
| **服务器位置与 ICP 备案** | 大陆的服务器用域名提供网站服务，**需要先做 ICP 备案**（个人也可以办，通常要一到几周）。香港服务器不需要备案，这是推荐香港的原因之一（见 [03 §3](03-system-architecture.md)） |
| **公网访问 ≠ 向公众提供服务** | 网站能从公网打开，但有密码保护、只有家人使用，仍然属于自用 |
| **各平台的使用条款** | 阿里云百炼、火山方舟、百度智能云、有道智云等开通接口都要**实名认证**；按条款正常使用即可 |
| **密钥安全** | 接口密钥和 GitHub 部署密钥只放在服务器上，不提交到任何仓库（本仓库的 `.gitignore` 已忽略 `.env`）；如果泄露，到控制台作废重建 |
| **AI 内容要标识** | 法规上的标识义务针对服务提供者，但打印的变式题和 AI 解析**仍然标注"AI 生成"**：让孩子知道这些题可能出错，发现问题要说出来 |
| **引导而不是代劳** | 双减的平台规则不适用，但讲解仍默认一步步引导，理由是学习效果（见 05 §3.6） |

### 1.3 如果以后要给别人用

一旦把这个工具开放给亲戚朋友或其他家庭使用（**哪怕免费**），就变成了"向公众提供服务"，以下事项要重新评估，v0.1 设计稿（git 历史中的 `08-compliance-and-landscape.md`）有详细清单：

- 生成式 AI 服务的属地登记，以及使用的模型须已备案
- AI 生成内容的显式和隐式标识（GB 45438-2025）
- 未成年人个人信息：监护人同意、专门处理规则、年度合规审计
- ICP 备案、App 或小程序备案、等保；教育 App 备案
- 双减相关规定（不能做"拍照搜答案"）

## 2. 隐私

孩子的卷子、笔迹和错题记录都是孩子的个人信息，自家用也要认真对待。

### 2.1 数据存在哪里

| 位置 | 存什么 | 注意 |
|------|--------|------|
| **GitHub 私有数据仓库** | 数据正本：表数据（JSONL）+ 卷子图片 + 评测集 | 必须是**私有**仓库；不加协作者；**永远不要改成公开** |
| 云服务器（香港） | 工作副本（数据仓库的克隆 + SQLite 索引）、PDF 缓存 | 服务器可以随时丢弃重建 |
| 公开代码仓库（本仓库） | 只有代码和通用资料 | **不放任何孩子的数据**，包括区、学校、照片、错题、评测题 |

**关于数据出境**：GitHub 是境外公司，数据存在境外服务器上。《个人信息保护法》第七十二条规定，自然人因个人或者家庭事务处理个人信息的，不适用该法，所以家庭自用不涉及出境评估之类的程序【中，非法律意见】。实际要做的是把账号和仓库的安全做好。

### 2.2 怎么保护

| 要点 | 做法 |
|------|------|
| GitHub 账号 | 开启两步验证，保存好恢复码；这个账号一旦被盗，数据就会泄露 |
| 服务器写数据仓库 | 用**部署密钥**（只对数据仓库有写权限），不用个人令牌 |
| 网站访问 | 全站 HTTPS + 家庭密码 + 登录限速；所有图片都要登录才能看；可选两步验证（见 [03 §4](03-system-architecture.md)） |
| 送给 AI 接口 | 只送题目区域的图片和文字；**送出前裁掉卷头**（姓名、班级、学校）。主流平台声明不用接口数据训练模型，各家的具体条款开通时确认一下 |
| 多一份备份 | 在家里电脑上 `git clone` 一份数据仓库，偶尔 `git pull` 一下 |
| 孩子知情 | 告诉孩子系统记录了什么、用来做什么；看板上不展示让孩子有压力的排名或比较 |

## 3. 供应商候选

### 3.1 手写擦除（第 ② 步的核心能力）

| 供应商 | 接口 | 价格线索 | 可信度 |
|--------|------|----------|--------|
| 百度智能云 | 文档去手写（`ocr/v1/remove_handwriting`） | 未查到；通常有免费调用额度 | 接口：高 |
| 有道智云 | 试卷手写体擦除（`ocr_writing_erase`） | 资源包 1 万次约 60 元（官方口径），**够用整个初三** | 中 |
| 合合信息 TextIn | 擦除手写（`text_auto_removal`） | 约 0.04 元/次；免费 5 次 | 中 |
| 新东方 AI 开放平台 | 自动擦除手写文字 | "低至 0.05 元/次" | 中低 |

**怎么选**：拿孩子自己的 10 页卷子（几何图、电路图、红笔批改都要有）在前三家各跑一遍，肉眼对比。公开渠道没有找到这些场景的实测对比，只能自己试。

### 3.2 切题与题目识别

| 供应商 | 接口 | 说明 |
|--------|------|------|
| 百度 | 试卷切题与识别（多模态，2026-06 更新）、试卷分析与识别 | 可以只切题，也可以切题加识别（异步）。**旧的公式识别接口即将下线，不要接入** |
| 腾讯 | 试卷切题 `QuestionSplitLayoutOCR`、数学试题识别 `EduPaperOCR` | 公式输出 LaTeX；返回题目中图片的坐标；首次开通送 1000 次 |
| 阿里 | `RecognizeEduPaperCut`、`RecognizeEduPaperStructed`、`RecognizeEduFormula` | 切题加结构化，自带矫正；公式接口只支持印刷体 |

> 也可以先不用专门的切题接口：直接让视觉大模型（如 qwen3-vl-plus）输出每道题的位置和内容，效果不够好再换专门接口。v0.1 两种都试，哪个准用哪个。

### 3.3 开源组件（想在本地跑、或者省钱时用）

| 用途 | 组件 | 许可证 |
|------|------|--------|
| 版面解析 + OCR + 公式 | PaddleOCR 3.x（PP-StructureV3、PaddleOCR-VL） | Apache-2.0 |
| 公式识别 | UniMERNet、Pix2Text、GLM-OCR | Apache-2.0 / MIT / MIT |
| 透视、弯曲矫正与去阴影 | UVDoc、DocRes | MIT |
| 电路图生成（寒假做图形变式时用） | schemdraw、circuitikz | 开源 |

**试卷去手写目前没有可直接使用的开源模型**（公开数据集 SCUT-EnsExam 仅限非商用，也没有现成权重），所以擦除还是用云端接口。

### 3.4 大模型

**Claude、OpenAI 的接口不支持中国大陆地区使用**，所以选用国内平台的模型。它们在北京直连稳定、中文数理能力强、价格低，而且都提供 OpenAI 兼容接口，和本仓库股票项目调用通义千问的方式一样。

## 4. 现成工具：能先顶上什么

在自己的工具做好之前，有些环节可以先用现成工具：

| 需要 | 现成工具 | 能不能先用 |
|------|----------|------------|
| 去手写、打印空白卷（第 ② 步） | **夸克扫描王"试卷去手写"**（App 内免费）、试卷擦除宝、蜜蜂试卷 | **能**。期中前可以先这样用；之后也可以作为擦除效果不好时的退路 |
| 错题收集和打印 | 错题打印机（喵喵机、得力等） | 能收集，但热敏纸会褪色、幅面窄，**做不了原位重做** |
| 讲题（第 ④ 步） | 夸克老师、有道小P | 能用，但容易直接给出答案 |
| 举一反三（第 ③ 步） | 学习机、华为错题本（只支持数学，最多 6 道相似题） | 推的是通用相似题，不贴合北京题型 |

**自己做的价值在于"串起来"**：三道关的"学透"判定和回炉机制、北京题位的本地化、按自家孩子的节奏调度和排版。单个环节，现成工具未必比自己做的差。

**一个提醒**：公开报道和投诉中，学习机类产品的"判题对错颠倒、解析前后矛盾、题库出错"并不少见。这正是本设计坚持交叉校验、并让家长兜底的原因。
