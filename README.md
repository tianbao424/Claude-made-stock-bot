# 🤖 AI股票聊天助手

基于 **React + FastAPI** 的现代化股票分析助手，集成 **AI问答** 和 **股票池管理** 功能。

## ✨ 主要功能

- **🤖 智能问答**：与AI助手实时对话，获取股票分析建议
- **📊 股票池管理**：完整的CRUD操作，支持标签和备注  
- **📋 表格视图**：专业的数据表格展示，一目了然
- **🔍 智能搜索**：按股票代码、名称、标签快速查找
- **📱 响应式设计**：支持桌面和移动设备

## 🚀 快速开始

### 安装和启动
```bash
# 安装依赖
npm install

# 一键启动系统
npm run dev
```

### 访问应用
- **前端界面**: http://localhost:3000
- **后端API**: http://localhost:8001

就这么简单！🎉

## 🎯 使用指南

### 股票池管理
1. **添加股票** - 点击"添加股票"按钮，填写基本信息
2. **管理标签** - 为每只股票添加分类标签
3. **添加备注** - 记录投资想法和分析笔记
4. **智能搜索** - 搜索框支持代码、名称、标签查找
5. **类型筛选** - 区分持仓股票和潜在标的

### AI智能问答
1. **实时对话** - 切换到"智能问答"标签
2. **股票查询** - 支持多种问题类型：
   - 实时行情："茅台现在多少钱"
   - 技术分析："分析比亚迪最近走势" 
   - 基本面："茅台财务状况怎么样"
   - 新闻资讯："宁德时代有什么新闻"
